## English

### The Problem

If you've ever found yourself in a situation like this:

![Problem - Too many alarms](https://i.imgur.com/mk51AKQ.png)

Then you know how frustrating it is to set multiple sequential alarms in Android. Managing dozens of alarms becomes a nightmare - setting new ones is a hassle, and finding old ones is even worse.

### The Solution

I tried to solve this myself with **AutoAlarm**, an app that allows you to set multiple alarms in one go:

![AutoAlarm App](https://i.imgur.com/qtXiU7V.png)

### Features

- **Set first alarm time** - Choose when your first alarm should ring
- **Set interval between alarms** - Define the time gap between each alarm
- **Set total number of alarms** - Specify how many alarms you need
- **Preview last alarm time** - See when your last alarm will ring before creating them
- **Compatible with your device's Clock app** - Works seamlessly with your phone's default alarm app
- **No ads** - Completely free and open source
- **Lightweight** - Simple and efficient

### Perfect For

- **Backup morning alarms** - Never oversleep again with sequential wake-up alarms
- **Power naps** - Set multiple alarms to ensure you wake up
- **Study sessions** - Regular reminders to take breaks or switch tasks
- **Medication reminders** - Multiple daily reminders at specific intervals
- **Any situation requiring sequential alarms** - Flexible for any use case

### How It Works

1. Set the time for your first alarm
2. Choose the interval between alarms (e.g., 5 minutes, 10 minutes, etc.)
3. Select how many alarms you want to create
4. Preview when your last alarm will ring
5. Tap "Create Alarms" - AutoAlarm automatically sets them in your device's Clock app

### Download

Download the latest APK from the [Releases](https://github.com/lorenzo-petrilli/AutoAlarm/releases) section.

### Installation

1. Download the APK file from the Releases section
2. Enable installation from unknown sources in your Android device settings (if needed)
3. Open the downloaded APK file and follow the installation instructions

### Compatibility

AutoAlarm works on various Android devices and automatically integrates with your phone's default alarm app.

## Italiano

### Il Problema

Se ti sei mai trovato in una situazione come questa:

![Problema - Troppe sveglie](https://i.imgur.com/mk51AKQ.png)

Allora sai quanto sia frustrante impostare più sveglie sequenziali su Android. Gestire decine di sveglie diventa un incubo - impostarne di nuove è un casino, e trovare quelle vecchie è ancora peggio.

### La Soluzione

Ho cercato di risolvere questo problema da solo con **AutoAlarm**, un'app che ti permette di impostare più sveglie in una sola volta:

![App AutoAlarm](https://i.imgur.com/qtXiU7V.png)

### Caratteristiche

- **Imposta l'ora della prima sveglia** - Scegli quando deve suonare la prima sveglia
- **Imposta l'intervallo tra le sveglie** - Definisci il tempo tra ogni sveglia
- **Imposta il numero totale di sveglie** - Specifica quante sveglie ti servono
- **Anteprima ultima sveglia** - Vedi quando suonerà l'ultima sveglia prima di crearle
- **Compatibile con l'app Orologio del dispositivo** - Funziona perfettamente con l'app sveglia predefinita del telefono
- **Nessuna pubblicità** - Completamente gratuita e open source
- **Leggera** - Semplice ed efficiente

### Perfetta Per

- **Sveglie di riserva mattutine** - Non dormire mai più troppo con sveglie sequenziali
- **Sonnellini** - Imposta più sveglie per assicurarti di svegliarti
- **Sessioni di studio** - Promemoria regolari per fare pause o cambiare attività
- **Promemoria farmaci** - Più promemoria giornalieri a intervalli specifici
- **Qualsiasi situazione che richieda sveglie sequenziali** - Flessibile per ogni caso d'uso

### Come Funziona

1. Imposta l'ora della prima sveglia
2. Scegli l'intervallo tra le sveglie (es. 5 minuti, 10 minuti, ecc.)
3. Seleziona quante sveglie vuoi creare
4. Visualizza l'anteprima di quando suonerà l'ultima sveglia
5. Tocca "Crea Sveglie" - AutoAlarm le imposta automaticamente nell'app Orologio del dispositivo
